# Vehicle Rental Management System

A console-based Java project demonstrating Core Java and OOP concepts.

## Concepts Used

- Encapsulation
- Inheritance
- Polymorphism
- Static
- Final
- Arrays
- For Loop
- While Loop
- If-Else
- Switch
- Access Modifiers

## Features

- Add Vehicle
- Display Vehicles
- Rent Vehicle
- Return Vehicle
- Search Vehicle
- Calculate Rent
- Display Total Vehicles

## Technologies

Java
